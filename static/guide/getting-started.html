快速开始 ​

本页说明如何拉取并运行 AntiCAP-WebApi 后端服务。

环境要求 ​

环境建议
Python3.10 或更高版本
Git用于拉取项目
系统Windows 或 Linux

克隆项目 ​

bash
git clone https://github.com/81NewArk/AntiCAP-WebApi
cd AntiCAP-WebApi

安装依赖 ​

bash
pip install -r requirements.txt

依赖包括 FastAPI、Uvicorn、SQLAlchemy、PyJWT、AntiCAP 等。

启动服务 ​

Windows ​

仓库提供了 Windows 启动脚本：

bat
Run-Windows.bat

也可以手动运行：

bash
python main.py

Linux ​

先给脚本执行权限：

bash
chmod +x Run-Linux.sh

启动服务：

bash
./Run-Linux.sh

也可以手动运行：

bash
python3 main.py

访问地址 ​

服务默认监听：

text
http://127.0.0.1:6688

Swagger 接口文档：

text
http://127.0.0.1:6688/docs

默认管理员 ​

服务启动时会自动创建或重置默认管理员：

用户名密码角色
adminadmin管理员

生产环境建议修改默认密码逻辑，避免长期使用默认管理员密码。

登录获取 Token ​

bash
curl -X POST "http://127.0.0.1:6688/api/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=admin"

返回示例：

json
{
  "access_token": "jwt-token",
  "token_type": "bearer",
  "role": "admin",
  "balance": 1000000
}

验证服务 ​

将登录得到的 Token 填入下面命令：

bash
curl "http://127.0.0.1:6688/api/tokens/verification" \
  -H "Authorization: Bearer <token>"

如果返回当前用户信息，说明服务已经正常运行。
