后端页面 ​

AntiCAP-WebApi 后端主要提供 API 服务，同时暴露了 Swagger 文档页面和静态页面入口。

Swagger 文档 ​

页面地址说明
开发者文档/docsFastAPI Swagger UI，用于查看和调试接口

后端将 FastAPI 默认文档地址关闭，然后自定义了 /docs 页面。Swagger 静态资源使用本地路径：

资源地址
JavaScript/swagger/swagger-ui-bundle.js
CSS/swagger/swagger-ui.css

如果访问 /docs 时页面样式或脚本加载失败，需要确认后端运行目录下是否存在对应的 static/swagger/ 资源。

静态页面入口 ​

代码末尾使用了以下挂载方式：

python
app.mount("/", StaticFiles(directory="static", html=True), name="static")

这表示后端会把运行目录下的 static 文件夹作为站点根目录提供访问，并支持 HTML 页面。

当前提供给文档项目读取的后端目录中没有 static 文件夹，因此只能确认后端预留了静态页面入口，无法从代码中列出具体页面内容。

可能的页面路径 ​

日志过滤器中排除了以下静态页面或资源请求，这些路径说明后端可能曾经配套过前端页面：

路径推测用途
/login/登录页面
/register/注册页面
/admin/管理后台页面
/myhome/用户中心或用户首页
/static/静态资源
/_next/Next.js 构建资源
/swagger/Swagger UI 本地资源

这些页面不在当前 AntiCAP-WebApi 目录中，若要让后端直接提供这些页面，需要补充 static 目录和对应构建产物。

后端启动入口 ​

后端入口文件是 main.py。直接运行时会启动 Uvicorn：

python
uvicorn.run(app, host="0.0.0.0", port=6688, access_log=True)

仓库还提供了两个启动脚本：

文件平台用途
Run-Windows.batWindows安装依赖并启动服务
Run-Linux.shLinux安装依赖并启动服务

默认管理员 ​

服务启动时会执行数据库初始化，并确保默认管理员存在：

用户名密码角色
adminadmin管理员

代码会在启动时把管理员密码重置为 admin。如果用于生产环境，建议先调整这段逻辑，避免默认密码长期暴露。
