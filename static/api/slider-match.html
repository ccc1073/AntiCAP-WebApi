缺口滑块 ​

识别缺口滑块验证码，返回滑块目标坐标。

接口信息 ​

项目值
地址/api/slider/match
方法POST
Content-Typeapplication/json
认证需要 Bearer Token
扣点普通用户扣点，管理员不扣点

请求体 ​

json
{
  "target_base64": "base64-image",
  "background_base64": "base64-image"
}
字段类型必填说明
target_base64string是滑块或缺口目标图片 Base64 字符串
background_base64string是背景图片 Base64 字符串

curl 示例 ​

bash
curl -X POST "$BASE_URL/api/slider/match" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{
    \"target_base64\": \"$TARGET_BASE64\",
    \"background_base64\": \"$BACKGROUND_BASE64\"
  }"

返回示例 ​

json
{
  "result": 136
}

返回值具体结构由 AntiCAP 滑块算法决定，通常表示滑块横向坐标或坐标结果。

错误码 ​

状态码说明
401Token 无效或过期
402余额不足

后端调用 ​

python
Atc.Slider_Match(
  target_base64=data.target_base64,
  background_base64=data.background_base64
)
